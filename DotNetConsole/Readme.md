# DotNet Console Solutions

This repository contains C# solutions for coding problems from LeetCode, Beecrowd (URI Online Judge), and HackerRank, implemented in a .NET Console application.

## Prerequisites

- .NET SDK (version 6.0 or later)
- xUnit for unit testing (already added)

## How to Run

1. Clone the repository:
    ```
    git clone <repository-url>
    cd DotNetConsole
    ```

2. Restore dependencies:
    ```
    dotnet restore
    ```

3. Build the project:
    ```
    dotnet build
    ```

4. Run the console application (replace `Program.cs` with your entry point if needed):
    ```
    dotnet run
    ```

5. Run tests (using xUnit):
    ```
    dotnet test
    ```

## Project Structure

- `LeetCode/`: Solutions for LeetCode problems.
- `Beecrowd/`: Solutions for Beecrowd problems.
- `HackerRank/`: Solutions for HackerRank problems.
- `Tests/`: Unit tests using xUnit.
